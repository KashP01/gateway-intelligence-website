# Gateway Intelligence — starter website

A responsive, single-page static website for the proposed Gateway Intelligence brand.

## Open locally

1. Unzip the download.
2. Open `gateway-intelligence-site` in Visual Studio Code.
3. Double-click `index.html` to open it in your browser, or install the optional VS Code Live Server extension and choose **Open with Live Server**.

## Before publishing

1. **Brand clearance:** Gateway Intelligence LLC is a proposed name only. Check Missouri Secretary of State availability and USPTO trademark conflicts. Do not imply an LLC legally exists until it is formed.
2. **Business email:** The contact address is set to `info@gatewayintelligence.com` in `index.html`. Verify email hosting or forwarding is active before launch. The inquiry form uses `mailto:`: it opens the visitor's mail app, it is not a backend form and does not reliably capture all inquiries.
3. **Claims:** Review all claims; ensure they reflect what you can actually deliver. Future AI, cybersecurity and software items are explicitly labeled future capabilities.
4. **Privacy & contact:** Before collecting contact details via a third-party form service, provide appropriate privacy notice and review the provider's terms. This demo stores no form submissions.
5. **Publish:** Upload the site to a static hosting provider (for example GitHub Pages, Cloudflare Pages or Netlify). Set the root folder to the folder containing `index.html`. A custom domain is optional.
6. **Fonts:** Google Fonts are loaded from the network; fallback system fonts render offline.
